    Glasses layout: Ray-Ban Display preview

    This is a web preview of the glasses layout, sized and styled for the Ray-Ban Display: a square, glanceable surface you read in under two seconds, with no scrolling. There is no separate public JavaScript SDK file to import for this; display web content is built with standard web tech, and this preview follows that model.

    Display600 × 600 px
    BackgroundPure black

    What you get here is the layout itself: fixed 600 × 600 square, pure-black background, high-contrast palette and voice input, ready to open in a browser. Treat the glasses tab above as a faithful preview of that layout, not a live connection to a paired pair of glasses from this page.

    How to use it in the shop

    1. Build the list: add everything in Phone view in this tab.
    2. Flip the view: switch this same tab to Ray-Ban Display to see the glasses layout with the same items. To shop from the actual glasses, open this page there and re-add or copy the list across, as this static page does not sync between devices.
    3. As you shop: the next item is shown huge. Tap Got it to tick it off and move on.
    4. Hands full? Use Add by voice in Phone view, or the arrow keys on a keyboard.
